# Нейро//Атлас — мозг в норме и при расстройствах

Интерактивный одностраничный сайт-презентация: как меняется мозг при
психических и неврологических болезнях по сравнению со здоровым мозгом.

## Структура каждого слайда

- **Верх (экран):** снимок мозга слева + 5 характеристик с иконками и статистика справа
- **Ниже (прокрутка вниз):** симптомы, «Что происходит в мозге», «Знаете ли вы?»,
  «Терапия и прогноз» с тегами — блоки плавно появляются при прокрутке

## Управление

- кнопка **→** справа / **←** слева — переход между диагнозами
- прокрутка / колесо / свайп вверх-вниз — подробности внутри слайда
- клавиатура: `←` `→` `Space`, `Home` / `End`
- точки-навигация внизу, прогресс-бар по нижнему краю

## Запуск локально

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Деплой на Vercel

1. **Импорт из GitHub:** Vercel → *Add New Project* → репозиторий.
   Framework Preset: **Other**, сборка не нужна — в корне готовый `index.html`.
   > Vercel деплоит production-ветку `main` — смёржите Pull Request с сайтом
   > (или смените Production Branch в Settings → Git).
2. **CLI:** `npm i -g vercel && vercel --prod`
3. **Drag & Drop:** перетащить папку на [vercel.com/new](https://vercel.com/new)
