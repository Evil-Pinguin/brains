# Нейро//Атлас — мозг в норме и при расстройствах

Стильный одностраничный интерактивный сайт-презентация: как меняется мозг при
психических и неврологических расстройствах по сравнению со здоровым мозгом.

## Слайды

| № | Слайд | Акцент | Снимок |
|---|-------|--------|--------|
| 01 | Здоровый мозг (норма — точка отсчёта) | зелёный | 3D-визуализация |
| 02 | Депрессия | синий | ПЭТ-скан |
| 03 | Шизофрения | фиолетовый | МРТ-скан |
| 04 | Биполярное расстройство (БАР) | оранжевый | снимки мозга |
| 05 | Болезнь Альцгеймера | красный | МРТ, атрофия |
| 06 | Тревожное расстройство | жёлтый | фМРТ, миндалина |
| 07 | СДВГ | голубой | фМРТ-сравнение |
| 08 | ОКР | розовый | ПЭТ-сравнение |

Каждый слайд: **снимок мозга слева**, **характеристики справа** (5 признаков
с иконками + статистика), круглая кнопка со стрелкой на правом краю экрана
перелистывает слайды с направленной stagger-анимацией перехода. На последнем
слайде кнопка превращается в «начать заново». Акцентный цвет интерфейса
меняется под каждый диагноз.

## Управление

- кнопка **→** справа / **←** слева
- клавиатура: `←` `→` `Space`, `Home` / `End`
- точки-навигация внизу
- свайп на тач-устройствах

## Структура

```
index.html        — разметка (8 слайдов, SVG-иконки)
css/style.css     — тёмная тема, анимации, адаптив
js/app.js         — логика слайдера
assets/           — снимки мозга
vercel.json       — настройки деплоя на Vercel
```

## Запуск локально

Статический сайт, любой веб-сервер, например:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Деплой на Vercel

1. **Импорт из GitHub (рекомендуется):** Vercel → *Add New Project* → выбрать
   репозиторий. Framework Preset: **Other**. Настройки сборки не нужны —
   корень репозитория уже содержит готовый `index.html`.
   > Важно: Vercel деплоит **production-ветку** (по умолчанию `main`).
   > Если сайт не отображается — проверьте, что в ветке `main` есть файлы
   > сайта (merge Pull Request), либо смените Production Branch в
   > Settings → Git.
2. **Через CLI:** `npm i -g vercel && vercel --prod` из корня проекта.
3. **Drag & Drop:** перетащить папку проекта на [vercel.com/new](https://vercel.com/new).
